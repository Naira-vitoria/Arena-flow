# Arena Flow — Modelo de Projeto Integrador adaptado

Este projeto foi adaptado a partir do modelo didático do professor. As orientações originais de execução e estrutura foram preservadas.

Consulte `README-ARENA-FLOW.md` para a descrição da adaptação e das funcionalidades desta versão.

## Executar

Use Node.js 20.19+, 22.12+ ou 24+. Na pasta do projeto, execute:

```bash
npm ci
npm start
```

Acesse http://localhost:4200.

## Verificar build

```bash
npm run build
```
